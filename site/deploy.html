Deploy to mainnet

Deploys SPACE, TariffOracle, Reserve and TariffRouter from your own wallet. Your connected address becomes the admin, treasury, minter, oracle updater, config and withdrawer, the same wiring as DeployMainnet.s.sol with ADMIN = you.

Real money. Every step is a mainnet transaction that costs real ETH and cannot be undone. Only continue if you have had legal review (see MAINNET.md). A single key controls everything. If you lose the wallet you lose admin; if it leaks, an attacker can mint and drain the reserve. Roles can be moved to a Safe later.
